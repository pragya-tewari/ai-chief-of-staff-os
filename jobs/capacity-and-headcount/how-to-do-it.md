# How to do it

Read the rules first.

## Run identity

Use the as-of date plus the organisation/project scope as the run key. Write to
the same deterministic report for that key; a rerun refreshes it after reading
the existing receipt and report rather than creating a second current version.

## Steps

1. **Who we have.** From `people/` and `org/roles.md` — the current team and what
   each owns.
2. **What we're committed to.** From `org/portfolio-map.md` and `projects/` — the
   live and planned work.
3. **The gap.** Where commitments exceed the people to do them — by role, by
   project.
4. **The cost to close it.** What a hire or a contractor would cost, against the
   budget source, and what happens if the gap isn't closed.
5. **Write the report to `reports/`** with the specific gaps and options —
   hire, contract, cut scope, or re-sequence.
