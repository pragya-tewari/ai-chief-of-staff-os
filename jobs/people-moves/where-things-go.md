# Where things go

| Output | Goes to | Needs a yes |
|---|---|---|
| The move plan and checklist | `workspace/reports/` | no |
| Update to the person's file | `workspace/people/<name>.md` | no |
| Reassigning tasks to real people | task source | **yes** |
| Telling anyone about their new tasks | chat / mail | **yes** |
| Sensitive notes about the move | `workspace/private/` | **yes** |

The plan is yours. Moving work onto someone, or telling them, always needs a yes.
Access changes are a checklist for you to act on, never done by the assistant.
