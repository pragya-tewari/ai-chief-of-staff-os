# When to run

Whenever a decision is somewhere in its life:
- **before** — it needs framing for a meeting where it'll be made;
- **align** — several people hold different positions and it's stuck;
- **record** — it just got settled and needs to be written down;
- **revisit** — months have passed and it's worth asking if it still holds.

Pick the mode for where the decision is. See [modes.md](modes.md).
