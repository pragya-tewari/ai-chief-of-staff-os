# Where things go

| Output | Goes to | Needs a yes |
|---|---|---|
| A decision pre-read (before mode) | `workspace/reports/` | no |
| An alignment write-up (align mode) | `workspace/reports/` or a project folder | no |
| A decision record (record mode) | `workspace/decisions/` | **yes** |
| A revisit note (revisit mode) | `workspace/reports/` | no |
| Open threads surfaced along the way | `workspace/registers/questions.md` | no |

Only the decision record — the claim that something is settled — needs a yes.
The packs and write-ups are yours to read.
