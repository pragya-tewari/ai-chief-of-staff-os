# Example

A request comes in, using the sample company's intake (request #1).

## Input

`run intake-a-request` on: "Can you add a gamified leaderboard to the courses
before the October rollout?" — from Omar.

## Output

**Request captured**
- Who: Omar. What: a gamified leaderboard feature. By: before the October rollout.

**Decision: decline (for now)**
- It serves no current goal; the three live goals are the rollout, onboarding
  time, and team adoption. It adds scope to a rollout that's already at risk on
  the vendor content. Cost outweighs it before October.

**Drafted no (waits for a yes to send)**
> Thanks for flagging this. I can see why a leaderboard would help engagement. For
> October I want to protect the rollout scope, which is already tight on the
> vendor side, so I'm going to hold this rather than add it now. Let's put it in
> the post-rollout list and look at it with real usage data. If you think it's
> rollout-critical, tell me why and I'll re-weigh it.

## What needs a yes

Sending the no. The capture and decision are yours to keep either way.
