# Where things go

| Output | Goes to | Needs a yes |
|---|---|---|
| The captured request and the decision | `workspace/reports/` | no |
| A task (when the answer is *do*) | task source | internal: no · external: **yes** |
| A parked item (when *defer*) | `workspace/registers/questions.md` | no |
| The drafted no (when *decline*) | `workspace/reports/` | no |
| Sending the no, or routing to someone | chat / mail | **yes** |

Capturing and deciding is free. Anything that reaches the asker — a no, a routed
request — needs a yes.
