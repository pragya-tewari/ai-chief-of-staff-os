# Where things go

| Output | Goes to | Needs a yes |
|---|---|---|
| The weekly system review | `workspace/reports/` | no |
| A promoted correction / new rule | `workspace/profile/overrides.md` | **yes** |
| A drafted playbook for a repeated task | `workspace/reports/` | no |

The review is yours. Changing a rule — even your own override — is proposed and
waits for a yes. The assistant never self-edits rules.
