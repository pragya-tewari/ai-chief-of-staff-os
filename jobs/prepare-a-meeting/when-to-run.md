# When to run

Before a meeting — a 1:1, a portfolio review, a board meeting, an all-hands, or a
meeting with an outside party. The cadence in the workspace's `org/cadence.md`
says which meetings recur and when; run this ahead of them.

The output is a prep pack in `reports/`, for you to read and take in. It is not
sent anywhere.

Its partner is `meeting-to-tasks`, which runs after the meeting.
