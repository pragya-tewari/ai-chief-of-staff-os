# Where things go

| Output | Goes to | Needs a yes |
|---|---|---|
| The prep pack | `workspace/reports/` | no |
| A filtered "what's owed" view | `workspace/reports/` | no |
| Sending an agenda to attendees (optional, separate step) | chat / mail | **yes** |

The pack is for the user. Nothing here reaches another person unless the user
explicitly asks to send an agenda, which is its own approved action.
