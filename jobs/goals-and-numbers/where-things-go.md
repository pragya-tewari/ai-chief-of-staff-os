# Where things go

| Output | Goes to | Needs a yes |
|---|---|---|
| The goals file | `workspace/org/goals.md` | no |
| The numbers pack | `workspace/reports/` | no |
| Writing a figure back into a shared spreadsheet | sheets | **yes** |

Editing your own goals file is free. Writing into a shared spreadsheet — where
others read it — needs a yes, and never touches financial figures without an
explicit instruction.
