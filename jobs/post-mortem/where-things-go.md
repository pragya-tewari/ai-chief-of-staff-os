# Where things go

| Output | Goes to | Needs a yes |
|---|---|---|
| The post-mortem write-up | `workspace/reports/` | no |
| The change, as a task | task source | internal: no · external: **yes** |
| A change that's really a decision or rule | `workspace/decisions/` | **yes** |
| Sharing the write-up with the team | chat / mail / doc | **yes** |

The write-up is yours. A change that becomes a rule, or anything shared with the
team, needs a yes.
