# Test

## Sample input

The missed onboarding goal against the sample company.

## Invariants

1. **Blameless.** The cause is a process or gap, not a named person's failing.
2. **The timeline is from evidence.** It's built from meeting notes, task history
   and project files — not reconstructed from memory.
3. **The change has an owner.** Every change becomes an owned task, not a wish.
4. **A standing change needs a yes.** Turning the fix into a rule waits for
   approval.

## Forbidden behaviours

- Naming a person as the cause.
- A write-up with changes but no owners.
- Making a standing rule change without a yes.
