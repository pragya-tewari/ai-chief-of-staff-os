# Where things go

| Output | Goes to | Needs a yes |
|---|---|---|
| The drafted message | `workspace/reports/` | no |
| A row in the comms log | `workspace/registers/comms.md` | no |
| Sending the message | chat / mail | **yes** |

The draft and the log are yours. Sending it — to anyone — always needs a yes,
with the exact text and recipient shown first.
