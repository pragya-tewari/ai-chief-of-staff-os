# Example

Using the sample company. Omar keeps sending client updates in a private DM
instead of the client channel.

## Input

`run draft-a-message` — redirect Omar to the client channel, without friction.

## Output — draft in `reports/msg-redirect-channel.md`

> Thanks for the update. Since this affects the rollout cadence and the rest of
> the team, could you post it in the client channel rather than here? We're trying
> to keep decisions and cadence changes in one place so nobody's working off a
> different picture. Not a big deal — just easier for everyone if it's all in the
> one thread.

**Risk note:** low. The one thing to avoid is sounding like a reprimand — the
draft acknowledges first, gives the reason (shared context), and stays light.
Omar prefers a heads-up before escalations, so a light nudge fits.

**Comms log:** C4 — to Omar, redirect to the client channel, draft.

## What needs a yes

Sending it. Until then it's a draft.
