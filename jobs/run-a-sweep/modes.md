# Modes

Four checks over the same data. Weekly, run all four; alone, run one.

| Mode | Looks for | Flags |
|---|---|---|
| `open loops` | Everything promised that isn't done | Overdue tasks, commitments with no movement, decisions with no owner |
| `task quality` | Tasks that will fail quietly | No owner, no due date, a vague one-line title, against the task-row standard |
| `risks and dependencies` | Cross-project trouble | Shared people, colliding dates, single points of failure |
| `workload` | Who's carrying what | Who's overloaded, who's blocked, who's quietly idle |

Same read, four lenses. The report says which check found each item.
