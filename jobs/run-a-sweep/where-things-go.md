# Where things go

| Output | Goes to | Needs a yes |
|---|---|---|
| The sweep report | `workspace/reports/` | no |
| A nudge to a person (offered, not sent) | chat / mail | **yes** |

The report is yours. If a finding needs a person to be chased, the job offers to
draft it — sending is a separate yes, usually via `draft-a-message`.
