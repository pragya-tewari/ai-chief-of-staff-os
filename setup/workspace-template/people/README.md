# People

One file per person you work with. Name the file by its stable id — `per-ravi.md`
— and keep the readable name in the header's `name:` field. Other files refer to
the id, so a person changing their name never breaks a reference.

Each file: role, what they own, working-style notes that are safe to share, and
open context. **Not their task list** — tasks live once, in the task source.

Header format: the product's `schemas/entity-header.md`.
