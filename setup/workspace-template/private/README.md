# Private

People-sensitive material — working-style observations, anything about a person
that isn't safe to share.

Two hard rules:
- The assistant reads or writes here only when you explicitly say so.
- Nothing here ever appears in an external-facing output — no message, shared
  doc, or report you send. If you use a cloud assistant, any private file you
  explicitly approve it to read is still processed by that provider.

Observations are patterns with evidence attached, never character verdicts.
