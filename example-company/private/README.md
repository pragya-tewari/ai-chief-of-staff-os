# Private (sample)

People-sensitive material for the sample company. In a real workspace this plane
is read or written only on explicit permission and never appears in an
external-facing output. A cloud assistant still processes a file when the user
approves reading it. Here the content is fictional and demonstrates the boundary:
interpretation and behavioural context go here; facts and stated preferences go
in `people/`.

Sample file: [people-notes.md](people-notes.md).
